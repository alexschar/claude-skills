Connecting the Office Printer

Every laptop in the front office needs the same shared printer added once. This guide covers turning it on, adding it to a laptop, and printing a test page.

What you need
Admin access on the laptop, about five minutes, and the printer's network address (ask IT if you don't have it).
Good to know
The printer stays on the office network once it's added — you will not need to add it again after a restart.
Flow Can/can't A Set up once (1–2) B Every print job (3) Done when

Part A · Set up once

1

Confirm the printer is online

Anyone · about 1 minute
Where
Settings → Network → Connected devices
Have ready
  • The printer's network name or address (ask IT if you don't have it).
  • Admin access on the laptop.
Do this
Check that Office-Printer appears in the connected-devices list.
Check
The list shows Office-Printer as online.
If it doesn't appear, the printer may be asleep — press any button on its panel and wait about 30 seconds, then check again.
2

Add the printer to your laptop

Anyone · about 5 minutes
Where
Settings → Printers & Scanners → Add Printer
Do this
  1. Click Add Printer.
  2. Select Office-Printer from the list, or type its address by hand.
  3. Click Add, then press Esc to close the window.
Check
Office-Printer appears in your printer list.

§If it doesn't show up in the list

Type the address by hand instead of browsing for it — copy block A below is the exact address IT uses.

Copy block A · Printer address
\\PRINT-SERVER\Office-Printer

Part B · Every print job

Nothing to set up here — just choosing the right printer by name.

3

Print a test page

Anyone · about 2 minutes
Where
any document → File → Print
Do this
Choose Office-Printer from the printer list, then click Print.
Check
A page comes out of the printer within about a minute.

Two ways to print — pick whichever fits the document.

Recommended

Print in black and white. Faster, and uses far less toner — the default for everyday pages.

Print in color. Choose Color in the print dialog for anything with photos or charts.
